## ⚡ Architectural & Performance Highlights

- **✨ Low-Overhead HTML5 Particle Matrix:** Optimized vanilla `<canvas>` rendering loop capturing interactive mouse kinematics and touch vectors at a deterministic **60 FPS** frame target.
- **📐 Fluid Responsive Compositing:** Utilization of modern CSS `clamp()` routines and layout constraints ensuring pixel-perfect typographical grid rhythm across all display scales (mobile to ultra-wide desktop).
- **🌌 3D Horizon Pitch Lift & Spatial Depth:** Implementation of hardware-accelerated **GSAP ScrollTrigger** coupled with CSS `transform-style: preserve-3d` for GPU-offloaded viewport drifts.
- **🚀 Micro-Footprint Architecture:** Zero reliance on heavy structural frameworks (React, Vue, Angular), minimizing bundle overhead, hydration delay, and main-thread evaluation bottlenecks.

## 🛠️ Step-by-Step Customization Guide

<details>
<summary><b>👇 Click here to expand the 5-minute non-technical deployment pipeline</b></summary>

<br/>

### Step 1: Fork the Repository

1. Log in to your GitHub account.
2. Navigate to the top right of this repository page and click **Fork**.
3. Create a copy under your personal account space.

### Step 2: Customize Text Content

1. Open `index.html` directly in the GitHub web interface or your preferred editor.
2. Locate the text string literals inside the HTML tags (e.g., heading titles, personalized notes, dates, and names).
3. Edit the text to replace them with your personalized romantic message.

### Step 3: Swap Asset Media (Images & Music)

1. Choose high-resolution media hosted online (e.g., [Pexels](https://www.pexels.com/) for free cinematic imagery).
2. Replace existing image `src="..."` URL pointers in `index.html` with your custom Pexels media links.
3. Replace background audio pointers with your desired audio file URL.

### Step 4: One-Click Live Serving via GitHub Pages

1. Go to your repository's **Settings** tab.
2. Select **Pages** from the left navigation menu.
3. Under **Build and deployment** > **Branch**, select `main` (or `master`) and click **Save**.
4. GitHub will automatically generate your live deployment link.
